# Solicitud de acceso — piloto (no técnica)

Este documento es la versión "para la contraparte académica/administrativa"
de la solicitud. Para el detalle técnico de OAuth/API, ver
`docs/duoc-integration/INTEGRATION_REQUEST.md`.

## Lo que se pide para el piloto

1. Autorización para invitar estudiantes voluntarios de una o dos carreras.
2. Un contacto de TI que pueda, **en una fase posterior y opcional**,
   evaluar la solicitud técnica de integración con Blackboard.
3. Nada de acceso a datos, sistemas o credenciales institucionales para
   ejecutar el piloto en sí — StudyFlow funciona sin eso (ver `PILOT_PLAN.md`).

## Lo que NO se pide

- Acceso a Blackboard u otro LMS durante el piloto.
- Datos personales de estudiantes fuera de los que cada estudiante ingrese
  voluntariamente en su propia cuenta.
